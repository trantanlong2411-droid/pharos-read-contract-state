How to reproduce using Pharos MCP

Connect a compatible MCP client to https://mcp.pharos.xyz/mcp. First call get_chain_info to confirm Chain ID 1672. For each function listed above, invoke eth_call with the target contract, the corresponding function selector as data, and the fixed block 0x1348ad4.

{
  "transaction": {
    "to": "0x51e2A24742Db77604B881d6781Ee16B5b8fcBE29",
    "data": "0x313ce567"
  },
  "block": "0x1348ad4"
}

This example reads decimals(). Replace data with one of the other selectors to reproduce the other reads. For ABI strings, decode dynamic string offset, length and UTF-8 contents; for unsigned 256-bit numbers, interpret the hex as an integer before scaling by token decimals.

Evidence and limitations

This page is a static publication of responses recorded through an AI.PHAROS MCP conversation at block 20,220,628. It is not a live blockchain query or a running MCP agent. Reviewers can independently reproduce the calls using the instructions above.

No funds or private keys are required for the read-only calls. Values refer only to this contract at the specified block; do not interpret them as the global LINK supply.
